# graffine documentation

Sources of the [graffine documentation site](https://vsukhor.github.io/graffine/),
built with [Zensical](https://zensical.org) and published to GitHub Pages.

## Layout

```text
zensical.toml          site configuration and navigation
Doxyfile               API reference generation (reads ../include)
CMakeLists.txt         `docs` target, enabled with -DBUILD_DOCS=ON
content/               Markdown pages
  index.md             Home
  build_install/       Build & Install
  tutorial/            Tutorial
  api/                 API Documentation; api/reference/ is generated by Doxygen
  development/         Development
  third_party.md       Third-Party Libraries
imgs/                  images used by the repository README
```

## Building locally

From this directory:

```sh
python3 -m venv .venv && source .venv/bin/activate
pip install zensical
doxygen Doxyfile     # optional: API reference
zensical serve       # http://localhost:8000
```

Alternatively, configure the library with `-DBUILD_DOCS=ON` and build the
`docs` target; the site is written to `site/`.

## Publishing

Pushes to `main` that touch `docs/`, `include/` or the workflow run
`.github/workflows/docs.yml`, which generates the API reference, builds the
site and deploys it to GitHub Pages.
