# Building the Docs

This site is generated by [Zensical](https://zensical.org) from the Markdown
sources in the `docs/` directory of the graffine repository. The full API
reference is generated by [Doxygen](https://www.doxygen.nl) from the library
headers and embedded in the site under `api/reference/`.

## Prerequisites

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install zensical
```

and Doxygen from your package manager (e.g. `sudo apt install doxygen`).

## Build locally

From the `docs/` directory of a graffine checkout:

```sh
cd docs
doxygen Doxyfile     # writes content/api/reference/
zensical serve       # preview at http://localhost:8000
```

`zensical build --clean` writes the static site to `docs/site/`.

!!! tip
    The Doxygen step is optional while editing the hand-written pages; only
    the *Full Reference* link needs it.

## Build with CMake

With Doxygen and Zensical on the `PATH`, configuring with `-DBUILD_DOCS=ON`
adds the `docs` target, which runs both steps:

```sh
cmake -S . -B build -DBUILD_DOCS=ON
cmake --build build --target docs
```

## Publishing

Pushing to `main` a change under `docs/` or `include/` runs
`.github/workflows/docs.yml`, which runs Doxygen and Zensical and deploys the
result to GitHub Pages.
