# API Documentation

The API documentation has two parts:

- **Hand-written guides** on this site: the [Header Map](headers.md), telling
  which header holds what, and the [Transformation Catalogue](transforms.md),
  listing every transformation with its arguments and result.
- The **[Full Reference](reference/index.html)**, generated by Doxygen from
  the comments in the library headers: every namespace, class, member and
  file.

[Open the full reference :lucide-external-link:](reference/index.html){ .md-button .md-button--primary }

## Namespaces

| Namespace | Contents |
| --- | --- |
| `graffine` | Project-wide definitions (`definitions.h`), errors, logging (`msgr`) |
| `graffine::structure` | Graph elements: `Graph`, `Component`, `Chain`, `Edge`, `Vertex`; analyzers such as `Adjacency`, `Connectivity`, `IntegralTests` |
| `graffine::structure::descriptors` | Ids, degrees, slots, ends and element descriptors |
| `graffine::structure::containers` | Containers of edges, chains, vertices and components |
| `graffine::structure::paths` | Path traversal over edges and over chain end slots |
| `graffine::structure::io` | PLY input/output (`Ply`) |
| `graffine::transforms` | Transformation functors, one sub-namespace per family |
| `graffine::utils` | Messaging, constants, miscellaneous helpers |

## Common type names

| Name | Meaning |
| --- | --- |
| `G::Compt`, `G::Component` | Connected component type |
| `G::Chain`, `G::Edge`, `G::Vertex` | Element types |
| `G::End` | Chain/edge end descriptor; `End::A`, `End::B` |
| `G::EndSlot`, `G::BulkSlot` | Slots on chain ends and chain interiors |
| `Deg1` ... `Deg4` | Vertex degrees |
| `EgIdG`, `ChIdG`, `CmpId`, `VIdH`, ... | Typed ids; see [Identifiers](../tutorial/identifiers.md) |
| `graffine::real` | `float`, or `double` with `GRAFFINE_REAL_IS_DOUBLE` |
