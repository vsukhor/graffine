# Third-Party Libraries

| Library | Use | License | How obtained |
| --- | --- | --- | --- |
| [tinyply](https://github.com/ddiakopoulos/tinyply) (modified) | PLY file I/O | Public domain / BSD-2-Clause | Bundled in `external/tinyply/` |
| [Google Test](https://github.com/google/googletest) | Unit tests | BSD-3-Clause | Fetched by CMake when `BUILD_TESTS=ON` |
| [Google Benchmark](https://github.com/google/benchmark) | Benchmarks | Apache-2.0 | Fetched by CMake when `BUILD_BENCHMARKS=ON` |

Parts of the utilities are also derived from
[vsukhor/utils](https://github.com/vsukhor/utils).

Only tinyply is part of what consumers of graffine receive; the others are
used for graffine's own development targets.

See [NOTICE](https://github.com/vsukhor/graffine/blob/main/NOTICE) in the
library repository for details.
